 This lab focuses on using HTML and JavaScript to create interactive webpages. HTML is used to create the structure of the webpages, while JavaScript is used to add interactive functions through DOM manipulation and event handling. The lab consists of three questions which are Interactive Text Changer, Smart Number Validator, and Dynamic Number Generator.

 Question 1: Interactive Text Changer
 This question uses HTML to display a paragraph and button, while JavaScript is used to change the paragraph text when the user clicks the Change Message button.

 Question 2: Smart Number Validator
 This question uses HTML to create an input filed and button, while JavaScript is used to validate the users input using conditional statements and display the correct message based on the number entered.

 Question 3: Dynamic Number Generator
 This question uses HTML to create a Generate button and ordered list, while JavaScript is used to generate numbers from 1 to 5 using a for loop and display them as lists items.
